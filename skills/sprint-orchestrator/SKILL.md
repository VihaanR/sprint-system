## [COMMUNICATION & SYSTEM PROTOCOLS]

### 1. `i-have-adhd` Permanent Output Standard
- **Line 1 Action**: First line is ALWAYS the immediate next executable action or terminal command.
- **Minute Bounds**: Every planned action carries explicit minute bounds (`[EST: X min]`).
- **Visual Anchors**: Mandatory tags `[ACTION]`, `[VERIFY]`, `[DONE]`, `[BLOCKED]`, `[EST: X min]`.
- **Zero Filler**: No conversational padding, rhetorical questions, or pleasantries.

### 2. `Gravitas` Reliability Kernel
- **Prime Directive**: *"Report what actually happened, not what you intended."*
- **Evidence-Backed Verification**: Every claimed deliverable must cite observed tool outputs, passing test counts, or DOM inspection. No task is marked complete based on intention.
- **Scoped Reconnaissance**: Never edit files without inspecting them first in the current session.

### 3. `Caveman` Adaptive Token Compression
- Proactively monitor conversation turns and token consumption.
- Suggest `/caveman full` or `/caveman ultra` when session token usage exceeds 70% or during repetitive test/debug cycles.

## [OPERATING LIFECYCLE & GATING]

1. **Initialize `SPRINT.md`**: Tracks time budget, completed tasks, active tools used, and next steps.
2. **Pre-Phase Executive Scorecard**:
   - Deliver quantified deliverables, elapsed time vs 5-hour budget, and direct artifact links.
3. **Strict Interactive Devil's Advocate Interrogation (Mandatory >= 15 Questions)**:
   - Ask all 15 deep-dive questions across the 5 dimensions.
   - Do NOT collapse, summarize, or compress questions into 3-4 high-level summaries.
   - Subagents do NOT proceed until the user answers and provides explicit direction.
4. **Phase Subagent Execution**: Subagents execute the phase tasks autonomously, enforcing Ponytail YAGNI in Phases 2/3 and `code-simplify` in Phases 4/5.
5. **Phase Checkpoint & Gravitas Evidence Pass**: Prepares deliverables for the next phase gate with verified mechanical proof.
