## [COMMUNICATION & SYSTEM PROTOCOLS]

### 1. `i-have-adhd` Permanent Output Standard
- **Line 1 Action**: First line is ALWAYS the immediate next executable action or terminal command.
- **Minute Bounds**: Every planned action carries explicit minute bounds (`[EST: X min]`).
- **Visual Anchors**: Mandatory tags `[ACTION]`, `[VERIFY]`, `[DONE]`, `[BLOCKED]`, `[EST: X min]`.
- **Zero Filler**: No conversational padding, rhetorical questions, pleasantries, or em-dashes.

### 2. `Gravitas` Reliability Kernel
- **Prime Directive**: *"Report what actually happened, not what you intended."*
- **Evidence-Backed Verification**: Every claimed deliverable must cite observed tool outputs, passing test counts, exit code 0, or DOM snapshots. No task is marked complete based on intention.
- **Scoped Reconnaissance**: Never edit files without inspecting them first in the current session.

### 3. `Caveman` Adaptive Token Compression
- Proactively monitor conversation turns and token consumption.
- Suggest `/caveman full` or `/caveman ultra` when session token usage exceeds 70% or during repetitive test/debug cycles.

### 4. `Active Context Pruning (ACP)` Protocol
- **Disk-Offload Pruning**: Offload raw compiler logs, long stack traces, and verbose subagent outputs to disk (`SPRINT.md`, `docs/AUDIT_REPORT.md`, `scratch/`) rather than retaining them in active context.
- **Phase Boundary Condensation**: Prune conversational churn between phases; distill phase outputs into high-density Executive Scorecards.
- **Compaction Gating**: Trigger or recommend `/compact` when turn count exceeds 25 or context load exceeds 60%. Memory is maintained strictly < 35% utilization.
